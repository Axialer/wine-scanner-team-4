# Вина

Сервис по фото этикетки находит карточку вина в каталоге. Если бутылки в каталоге нет, отвечает, что совпадения нет, и показывает похожие вина. В чате можно также написать сорт, вкус или еду: сервис подберёт карточки по тексту, без распознавания фото.

## Что посмотреть

- **Каталог** — все вина. Поиск фильтрует уже загруженный список. Крестик в поле очищает запрос. Слово «Вина» в шапке возвращает к началу каталога.
- **Распознавание, фото** — снимок этикетки. Если вино узнано, в ответе одна карточка.
- **Распознавание, текст** — например «совиньон к рыбе». В ответе ближайшие вина каталога.

## Запуск в Docker

Нужны папки `data/` (каталог и фото) и `index/` (эмбеддинги). В образ они не копируются: тысячи картинок остаются на диске и подключаются томами. Без этих папок контейнер поднимется, но каталог и распознавание не заработают.

```bash
docker compose up --build
```

Интерфейс: http://127.0.0.1:8092/

Образ ставит CPU-сборки PyTorch и ONNX Runtime. Видеокарта не нужна для старта. Если на машине есть CUDA и в образ поставить GPU-колёса, сервис сам выберет GPU.

Переход на CUDA (многогигабайтные колёса, ставить отдельно):

1. В `Dockerfile` заменить индекс PyTorch `https://download.pytorch.org/whl/cpu` на индекс нужной версии CUDA, например `cu124`.
2. В `requirements.txt` заменить `onnxruntime` на `onnxruntime-gpu`.
3. Собрать образ заново: `docker compose up --build`.

## Запуск без Docker

```bash
python -m venv venv
venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
uvicorn api.server:app --app-dir src --host 0.0.0.0 --port 8092
```

На Linux и macOS активация: `source venv/bin/activate`.

При старте один раз пишется выбранное устройство, например `Device: siglip=cpu, ocr=cpu`. Если `torch.cuda.is_available()` и у ONNX Runtime есть CUDA, SigLIP и OCR идут на GPU. Если GPU нет, остаётся CPU, процесс не падает.

## Точность

Тестовые фото: `data/real_photo/`. Разметка 18 снимков: `data/eval/real_photo_labels.json`. На этих 18 фото текущий прогон даёт **16/18** точных slug. Это тот же уровень, что лучший сохранённый прогон в `data/eval/real_photo_dual_ocr.json` (тоже 16/18).

Два снимка по-прежнему не считаются точным попаданием: «Декантер. Формула Q» и «Мерло Литавщук». У первого ближе соседняя этикетка той же линейки, у второго — другая бутылка. Сервис их не выдаёт за уверенное совпадение. Линейная голова дообучения выключена (`index/finetune_enabled.txt`).
